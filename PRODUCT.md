# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS, no build step, no framework (confirmed by the author). Published from a public GitHub repository through GitHub Pages (confirmed).

## Users

University students of Arquitectura de Computadores (03306), UNED, with basic programming and computer-architecture knowledge. They open the resources on their own to study, review or prepare for evaluations, usually on a laptop and sometimes on a phone. Secondary user: the tutor, who shares one link with the group.

## Product Purpose

One public site that gathers the tutor's interactive learning resources for the course, so students reach all of them from a single link. Success: a student understands what each resource is for, picks the right one for what they are studying, and can move between them without getting lost.

## Positioning

Resources built by the course tutor around the exact concepts of the course (Stallings, cap. 19: microoperations, control signals, instruction cycle), in Spanish, interactive and runnable in any browser without installing anything.

## Operating Context

- Resource 1, CPU Quest: Misión Unidad de Control (`cpu-quest.html`): six-level educational game with an animated CPU, progress saved in localStorage.
- Resource 2, Von Neumann en movimiento: cycle-by-cycle animation of a 5 + 3 program comparing Von Neumann and Harvard bus usage.
- Resource 3, Glosario bilingüe de Arquitectura de Computadores: searchable English/Spanish glossary with diagrams, a LOAD example and a CPU animation.
- Sources of resources 2 and 3: `D:\ODrive\OneDrive - Universidad Estatal a Distancia\Tutorías UNED\Arquitectura de Computadoras\Animación\`.

## Capabilities and Constraints

- Portal home page plus each resource as its own HTML page, with shared navigation back to the portal (confirmed).
- Each resource must keep working as it does today; integrating it must not break its behaviour.
- Must run on GitHub Pages and from local files in Chrome, Edge and Firefox.
- Resources currently have independent visual styles (CPU Quest dark navy; Von Neumann dark IBM Plex; Glosario light blue).
- Open: whether more resources will be added later (structure should allow it).

## Brand Commitments

- Credit line: "Creado por Ing. Heiner Guido Cambronero, Lic." (exact wording confirmed; "autor intelectual" was explicitly rejected).
- Course identity: Arquitectura de Computadores (03306) · UNED.
- Language: Spanish, clear and close to the student.

## Evidence on Hand

The three working resources listed above. No student testimonials, usage numbers or grades exist; do not invent them.

## Product Principles

1. Get the student to the right resource in one step.
2. The resources are the content; the portal presents them, it does not compete with them.
3. Everything works offline-capable and without installation.
4. Concepts and terminology stay faithful to the course (Stallings cap. 19).

## Accessibility & Inclusion

Students may use phones and varied devices; pages must work at phone width and with keyboard navigation.
